## 维护边界

- 公开部分是词卡读取与浏览器偏好；表达、对谈、模型配置和写入必须经过管理员/私有守卫。
- 先读 `src/shared/expressions.ts` 和服务端读出口，不让模型返回的英文冒充库存原文；界面调整不改 24 小时与时间线判定。
- 阅读状态只在内存里，界面语言与主题才进浏览器偏好存储。私人查询、草稿与模型密钥不进入公共日志或种子。
- `pnpm dev` 和服务启动会应用迁移，带新迁移运行前先做一致性备份。本轮没有新增迁移或依赖。
- 提交明确列出路径，避免把已跟踪的 `.claude/settings.local.json` 或 tmp 生成物带入。用户本轮已授权项目文档与代码的本地提交，推送/部署需另有明确指令。
