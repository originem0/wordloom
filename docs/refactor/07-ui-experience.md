# 当前界面与阅读体验

最后更新：2026-11-26。本文件描述当前代码；01、02、03 和旧整合计划中的界面与施工步骤属于历史背景。对谈协议以 [06-talk.md](06-talk.md) 为准，交付与预算记录见 [04-progress.md](04-progress.md)。

## 1. 入口与权限

| 地址 | 作用 | 可见范围 |
|---|---|---|
| `/` | 管理员的表达库；访客转到词库 | 先等待认证查询，访客不挂载私人页面 |
| `/cards` | 搜索、翻阅和自检词卡，管理员另可生成与删除 | 公开读取，写入受保护 |
| `/talk` | 持久对谈、流式、批注、回顾与点击朗读 | 管理员 |
| `/providers` | 模型连接、探测、路由与 Rime | 管理员 |
| `/settings` | 浏览器偏好；管理员另可改服务端设置 | 公开，私有部分按认证加载 |
| `/login` | 登录，或继续浏览词库 | 公开 |

权限和私人字段遮挡仍由服务端决定。界面不会把收藏量、词卡自检或刚看过答案的应用算作独立产出。

## 2. 界面语言与存储

界面语言为简体中文或英语，立即作用于导航、操作、日期、错误和通知。`src/client/lib/i18n.ts` 的 `translate` 在调用时读取当前偏好，异步完成的消息跟随当时的语言；已有错误用代码或原始错误保存，不把译文锁在状态里。

`uiLanguage` 与 `theme` 才进入 `app-store`。浏览器存储受阻时偏好仍能在内存里工作；客户端测试使用内存存储，不依赖 Node 的全局 localStorage。管理员的 `analysis_language` 只控制新生成词卡的解释性内容，已有原文、词卡图解、对谈内容、批注与未保存设置不因界面切换改写。

临时阅读状态在 `src/client/store/reading.ts`：词卡输入、级别、分页组合，表达查询、分栏、页码以及滚动位置。它们跨页面保留，不进 URL 或持久存储，刷新后重新开始，成功退出登录时清空。恢复滚动先等列表就绪，避免在空加载页被压成零。

## 3. 词卡

### 阅读顺序

卡头保留单词、音标、词性与 CEFR，接着是核心意象、完整图解、词源，以及可展开的场景、家族对比和边界测试。

用户最终明确撤掉了顶部直接中文释义、先看一句的例句预览和更多评分信息。WAD/WAP、分级例句等仍在数据/API 中，不额外铺在详情顶部。列表继续显示简短释义；用法例句通过场景激活查看。

核心图解直接展示已保存内容，不再给同一段内容加简化翻译或完整图解折叠。这让界面语言与生成内容语言保持各自的作用范围。

### 图与主题

account、grim、compromise、assume 使用代码中人工校对的场景图，避免只改某一本机数据库才能得到新图。其余优先使用已保存的模型 SVG，缺失时使用既有五种图式模板。

模型 SVG 始终作为 `<img>`，解析和序列化只用于字号、位置与主题呈现，不插入页面 DOM、不回写数据。代码图作为受控 React SVG。词卡使用主站表面与文字色；`--word-*` 变量只负责词卡呈现，不覆盖控件使用的全局 `--card`、`--muted`。

按实际容器计算图内字号补偿。390px 验收的七张样本标签最小为 14.0–14.93px；深色正文与辅助文字在词卡表面的对比度约为 5.70 和 4.55。此结果来自样本浏览器检查，不宣称所有未来模型布局都已人工验证。

### 详情、对比与自检

详情用 `?card=<id>` 接入浏览器历史，返回先关详情，关闭后焦点回原按钮。直接打开的详情链接也有返回词库的路径。桌面和手机使用 Radix Dialog 的焦点与滚动锁定，手机全屏；弹窗作为单一滚动文档，避免固定高度挤压折叠区。

桌面保留四列家族对比，手机先显示词与核心区别，语域/场景随后展开。边界测试先选择，再显示参考判断和各选项解释；旧情境格式使用适用、不适用、视情境而定三个选择。可再次尝试，但没有写入表达练习、升级或产出统计。

实现见 `src/client/components/cards/CardCollection.tsx`、`PrototypeWordCard.tsx`、`CoreImageVisual.tsx`、`ReviewedCoreImage.tsx` 与 `prototype-word-card.css`。

## 4. 表达库

全部、想用、见过、已收起四栏沿用既有状态；全部不含已收起。先按原文、焦点、提示句与出处在浏览器里筛选，再每页 20 条渲染，私人查询不进入请求 URL。

搜索和分栏切换回第一页；翻页滚回列表开头。归档使最后一页消失时，显示和记住有效页码，后来另一个条目到达也不会跳回被移除的页。新收下的条目转到全部第一页。

没有到期条目时，可以从见过选择一条并直接聚焦自己的提示句。放进想用紧邻提示句；备注、补注、出处与学习记录随后展开。空想用栏和空库提供对应的开始入口；过滤无结果可清除过滤。

学习统计仍是用出过、可测日、作答日和判定日期，资格说明可展开。分页条数是当前浏览范围，不是掌握量。24 小时、1/3/7/14/30 天间隔、遮挡、队列容量和推翻规则都在既有服务端/折叠函数中，界面不绕过它们。

实现见 `src/client/components/expressions/ExpressionsPage.tsx`、`ExpressionDetail.tsx`、`TryPanel.tsx`、`StatsLine.tsx` 与共享 `src/client/components/ui/pagination-controls.tsx`。

## 5. 对谈、配置与登录

新对话有一个开场例子，只填输入框，不自动发送。回复前提供听语音和查看学习反馈；反馈入口滚到反馈区并转移键盘焦点，避免先读完长回复才能找改法。旧对话、回复和批注仍按当前遮挡状态读取，切换界面语言不会重写内容或重启播放。

配置用生成词卡、补充意象/辨析/测试、抽词等功能用途解释路由；路由有可见的未测试、可用或失败文字。密钥已保存不表示调用已验证；测试结果按既有 sessionStorage 缓存。设置标题和主要输入/操作保持同一尺度，维护项仍可展开。

登录页提供继续浏览词库，不需要为了公开阅读输入口令。其余登录、模型和私有 API 行为保持既有接口。
