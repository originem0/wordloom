# 当前界面与阅读体验

最后更新：2026-11-27。本文件描述当前代码；01、02、03 和旧整合计划中的界面与施工步骤属于历史背景。对谈协议以 [06-talk.md](06-talk.md) 为准，交付与预算记录见 [04-progress.md](04-progress.md)。

## 1. 入口与权限

| 地址 | 作用 | 可见范围 |
|---|---|---|
| `/` | 管理员的表达库；访客转到词库 | 先等待认证查询，访客不挂载私人页面 |
| `/cards` | 搜索、翻阅和自检词卡，管理员另可生成与删除 | 公开读取，写入受保护 |
| `/talk` | 持久对谈、流式、批注、回顾与点击朗读 | 管理员 |
| `/providers` | 模型连接、探测、路由与 Rime | 管理员 |
| `/settings` | 浏览器偏好；管理员另可改服务端设置 | 公开，私有部分按认证加载 |
| `/login` | 登录，或继续浏览词库 | 公开 |

权限和私人字段遮挡仍由服务端决定。界面不会把收藏量、词卡自检或刚看过答案的应用算作独立产出。

## 2. 界面语言与存储

界面语言为简体中文或英语，立即作用于导航、操作、日期、错误和通知。`src/client/lib/i18n.ts` 的 `translate` 在调用时读取当前偏好，异步完成的消息跟随当时的语言；已有错误用代码或原始错误保存，不把译文锁在状态里。

`uiLanguage` 与 `theme` 才进入 `app-store`。浏览器存储受阻时偏好仍能在内存里工作；客户端测试使用内存存储，不依赖 Node 的全局 localStorage。管理员的 `analysis_language` 只控制新生成词卡的解释性内容，已有原文、词卡图解、对谈内容、批注与未保存设置不因界面切换改写。

临时阅读状态在 `src/client/store/reading.ts`：词卡输入、级别、分页组合，表达查询、分栏、页码以及滚动位置。它们跨页面保留，不进 URL 或持久存储，刷新后重新开始，成功退出登录时清空。恢复滚动先等列表就绪，避免在空加载页被压成零。

## 3. 词卡

### 阅读顺序

卡头保留单词、音标、词性与 CEFR（新生成的卡另有词类标签），接着是核心意象、词源、边界测试，然后是家族对比、我收过的原句（仅管理员）、搭配与例句、场景激活四个折叠区。

用户最终明确撤掉了顶部直接中文释义、先看一句的例句预览和更多评分信息，这一条仍然有效：WAD/WAP、分级语境仍只在数据/API 中，顶部不加任何块。搭配、短语、三句例句、易混词和反义词原先生成并存储却从不显示，现在收在靠后的"搭配与例句"折叠区里，默认关闭；搭配与短语去重合并。列表继续显示简短释义。

测试排在家族对比之前，是因为对比表的典型场景就是测试题的场景，先看表等于先看答案。家族对比因此默认折叠，第一次显示答案后自动展开；读者手动开合过就不再替他决定。没有测试题的卡直接展开对比。

核心意象直接展开。新生成的图、说明和英文例句讲同一个场景。例句属于这个用法，分级例句仍在「搭配与例句」里。

### 图与主题

旧卡里的 grim、动词 resume 和 spontaneous 有三组人工编写的意象。grim 画读报告时紧锁的眉头，resume 画午休前后同一场预算讨论，spontaneous 直接写演讲结束时的掌声。每组都带对应的英文例句，图内标签和人工说明跟随界面语言。已保存的新式场景整组显示，保留生成时的解释语言。

其他旧卡沿用原说明。account、compromise、assume 使用既有的人工图，其余优先使用保存的 SVG，缺图时使用已知图式的模板。`none` 配说明时只显示文字。模型 SVG 始终作为独立的 `<img>`，源码保持原样，呈现时按容器补偿标签字号并调整配色。

打开单张词卡或一条表达时，浅色详情以燕麦色 `#F2E8D5` 为底，图面用 `#ECE1CD`，重点标记用墨青色 `#245C54`。表达原文选中的片段另加浅绿底与实线。深色详情使用暗青底和浅青重点色。两个列表页使用应用主题。

### 详情、对比与自检

详情用 `?card=<id>` 接入浏览器历史，返回先关详情，关闭后焦点回原按钮。直接打开的详情链接也有返回词库的路径。桌面和手机使用 Radix Dialog 的焦点与滚动锁定，手机全屏；弹窗作为单一滚动文档，避免固定高度挤压折叠区。

家族对比按"区分轴 → 怎么选 → 关键边界 → 表"的顺序读：前两行只有新生成的卡才有；关键边界一对一行，旧卡的单段文字在句末的 "X vs Y" 处切开（`card-detail.ts` 的 `splitBoundaryNote`）。桌面保留四列表，手机每个词一张卡，语域和场景直接列出，不再嵌套折叠。家族里的其他词可点：把词填进词库搜索框并关闭详情，有卡就看到卡，没有卡管理员可以直接生成。

边界测试一次一题，带进度。先选择，再显示参考判断和各选项解释；可再试一次，再进入下一题，最后一题之后给出"第一次就选对几题"，重试不计入。旧情境格式使用适用、不适用、视情境而定三个选择。选项顺序由词卡、轮次、题号和重试次数算出的种子打乱（`shuffleOptions`）：模型几乎总把合适的词写在第一个（本机 100 张卡的 334 道题里有 306 道），按存储顺序显示等于把答案排在最前。同一题在重新渲染之间顺序不变。自检结果只在页面内存里，没有写入表达练习、升级或产出统计。

### 我收过的原句

管理员展开后才读取表达库，复用 `useExpressions` 的私人缓存和失效规则，不另建按词缓存或查询接口。只匹配条目的原文，排除已收起、`masked` 或无原文的摘要；不读取隐藏字段、学习记录或对谈历史来补足命中。展开、查看记录和重试均不发起模型调用、不写学习记录、不计为练习。

匹配完整单词，不把 `car` 命中到 `care`；已知名词和动词兼容常规词形，未知词性只找原词，不猜不规则变化。短语保留词间分隔符，避免跨标点拼出一个并不存在的短语。焦点中的命中优先，其余沿用表达库由新到旧的顺序；同一句原文因不同焦点重复收藏时只显示一次，优先链接到焦点包含当前词的条目。每条只显示一个命中片段，长原文在命中两侧各保留约 120 个字符，突出当前词，附出处和日期。默认显示三条，随后每次多看三条；空库、无匹配、加载和失败分别反馈，失败时不继续显示旧缓存片段。

原句链接只携带数字 id（`/?expression=<id>`），不把原文或私人筛选词放进 URL。点击后打开既有表达详情；从词卡进入的记录关闭后返回原词卡，直接打开的链接关闭后回到表达列表并保留查询参数。原有表达筛选和分页不重置。详情仍经过服务端遮挡；若条目在两次读取之间进入想用，打开记录也不会直接显示答案。

实现见 `src/client/components/cards/OwnSentencesSection.tsx`、`card-detail.ts` 和 `src/client/components/expressions/ExpressionsPage.tsx`。

### 生成内容

以下只影响此后新生成的卡，已有的卡不迁移、不重新生成。

表层提示词不再要求 contextLadder、phrases、synonyms：前者与三句分级例句重复，后两者并入 4–6 条搭配，近义词由家族对比承担。对应的列和校验保留，旧数据照常读取。

深层提示词先判断词类，再选一个具体用法。`coreImageText` 描述场景里能看出词义的细节，`coreImageExample` 保存同场景英文例句，`coreSvg` 按需生成。图默认静态，过程可以用前后两幅说明。纯文字场景使用 `coreSchema: "none"`。例句与家族的区分轴、选择规则、边界说明一起保存在现有 `schemaAnalysis` JSON 列。旧数据仍可缺少这些字段。

三条家族说明的校验是宽松的：模型给了数组就拼接，给了读不懂的东西就丢弃这一条，不让整层失败。两个提供方共用 `ai-normalize.ts` 的 `normalizeCoreSchema`，认不出的图式标签归为 `none`；此前归为 `blockage`，任何放不进五种图式的词都会画一堵墙。

2026-11-26 用实际配置的模型各跑了一次（只读设置，不写库）：spontaneous 判为 abstract、`none`、不画图；withstand 判为 spatial、`blockage`、带 SVG；两者都给出三条轴、一句选择规则和每行一对的边界说明，并通过校验。两个词不构成对模型稳定性的评估。

三张样卡的图文在 `src/client/components/cards/CoreImageScenes.tsx`，场景选择与显示在 `CoreImageVisual.tsx`。生成规则见 `src/server/services/ai-prompts.ts`，数据校验见 `src/shared/validation.ts`。

## 4. 表达库

全部、想用、见过、已收起四栏沿用既有状态；全部不含已收起。先按原文、焦点、提示句与出处在浏览器里筛选，再每页 20 条渲染，私人查询不进入请求 URL。

搜索和分栏切换回第一页；翻页滚回列表开头。归档使最后一页消失时，显示和记住有效页码，后来另一个条目到达也不会跳回被移除的页。新收下的条目转到全部第一页。

没有到期条目时，可以从见过选择一条并直接聚焦自己的提示句。放进想用紧邻提示句。空想用栏和空库提供对应的开始入口；过滤无结果可清除过滤。

普通详情首先显示逐字保留的原句。有批注的片段带下划线，点一下即可切换解释。练习焦点有对应批注时默认显示该处，否则显示原句中的第一处批注。桌面批注在原句右侧，手机全屏并把批注紧接在原句下方。重复词按选中位置分别保存，重叠片段可以在批注里切换。整篇详情共用一个滚动区域，顶部保留关闭按钮。关闭后焦点回到打开它的条目，条目已删除或被过滤时回到列表区域。

选中原文后点「写批注」，也可先打开选区输入框，用键盘或触屏选取文字。每处批注可以附一组同场景例句。片段批注独立保存，写入只比较正在编辑的这一处，失败保留草稿。进入想用时，练习焦点仍只有一个。迁移 0013 新建批注表，旧原句和整条笔记可直接读取。

学习笔记默认以正文显示，点「编辑笔记」进入备注编辑区。「预览笔记」保留草稿，顶部的「保存」只发送修改过的字段。笔记中的分段、标题、列表、加粗、斜体、行内代码、高亮与有效的 Markdown 表格按内容排版。桌面表格在手机变成逐项对照。只折叠明确以「延伸」「拓展」「更多例句」等标题标出的补充内容。原文、提示句、出处与反馈始终按字面显示，笔记中的 HTML 和链接也保持字面文本。

旧种子中仅含来源标签和逐字重复原句的笔记收在底部「出处与原笔记」里，仍可查看和编辑。带有额外解读的笔记直接展开。学习记录排在出处之后。

「补注 · AI 写的」与「回想与练习」默认展开，都可以手动折叠。已有补注直接按行阅读，缺少时点「生成补注」。打开详情只读取已保存的内容。新补注先说明表达在这句里的意思，再按需给出可复用的句式或相关区别。回想提示和练习焦点默认以文字显示，点「编辑提示与焦点」可填写提示、选择已批注的片段或自填焦点。需要回想的条目先显示提示，点「看答案」后才显示原文、练习焦点、个人笔记和 AI 补注。关闭后重新遮挡。

详情顶部的「更多」提供收起或恢复，以及永久删除。见过、想用和已收起的条目都可以删除。确认后通过私有 `DELETE /api/expressions/:id` 删除该条及其整条学习时间线。对谈仍保留，读旧对谈时忽略已经不存在的命中。删除失败保留原记录与未保存内容，执行中禁用其他写操作。成功后关闭详情并刷新共享列表和统计，删除最后一页的条目时回到有效页码。旧读取和迟到的补注不能把删除的记录重新放回缓存。

维护者明确授权将当前 40 条笔记表达加入 `seed/expressions.json` 与现有数据库压缩包。内容包含原文、焦点、提示句、释义、笔记及来源标签；省略本机路径、实际学习流水、对谈和配置。初始来源记录只供展示，39 条见过、1 条已收起，不预设用出或毕业进度。运行时新增内容不会自动回写公共种子。

学习统计仍是用出过、可测日、作答日和判定日期，资格说明可展开。分页条数是当前浏览范围，不是掌握量。24 小时、1/3/7/14/30 天间隔、遮挡、队列容量和推翻规则都在既有服务端/折叠函数中，界面不绕过它们。

实现见 `src/client/components/expressions/ExpressionsPage.tsx`、`ExpressionDetail.tsx`、`TryPanel.tsx`、`StatsLine.tsx` 与共享 `src/client/components/ui/pagination-controls.tsx`。

## 5. 对谈、配置与登录

新对话有一个开场例子，只填输入框，不自动发送。回复前提供听语音和查看学习反馈；反馈入口滚到反馈区并转移键盘焦点，避免先读完长回复才能找改法。旧对话、回复和批注仍按当前遮挡状态读取，切换界面语言不会重写内容或重启播放。

配置用生成词卡、补充意象/辨析/测试、抽词等功能用途解释路由；路由有可见的未测试、可用或失败文字。密钥已保存不表示调用已验证；测试结果按既有 sessionStorage 缓存。设置标题和主要输入/操作保持同一尺度，维护项仍可展开。

登录页提供继续浏览词库，不需要为了公开阅读输入口令。其余登录、模型和私有 API 行为保持既有接口。
