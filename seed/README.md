# 可选的初始数据

2026-11-27 更新。维护者已明确授权公开当前英语笔记整理的表达内容。

`wordloom-seed.db.gz` 包含 3,380 张词卡、301 条语块、40 条表达，以及每条表达的一条初始来源记录。数据库迁移已更新至 0012；启动不会重复创建表达或对谈表。

`expressions.json` 保存同一批表达，便于直接查看。保留原文、焦点、提示句、AI 提示、释义、笔记、归档状态、导入时间和来源标签；不同焦点的相同原文仍是独立表达。原先收起的一条继续收起，所以初始列表显示 39 条。

压缩包没有模型配置、密钥、登录会话、任务、对谈、故事、旧练习或实际学习流水。没有复制本机来源路径、原始上下文和试写；初始来源记录只供展示出处，不计为用出、毕业或练习进度。

按根 [README](../README.md#导入已有词库可选) 的说明，在首次启动前解压到 `data/app.db`。已有数据库时不要覆盖；这不是完整的个人数据备份，也不会与运行中的数据库自动同步。应用内永久删除只改当前数据库，不改这份静态快照或 Git 历史。
